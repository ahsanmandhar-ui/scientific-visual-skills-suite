# Editorial Scientific Infographic Design Guide

## 1. Canvas Formats & Reading Distance
| Preset | Physical Size | Aspect Ratio | Primary Use Case |
|---|---|---|---|
| `editorial-legal` | `8.5 × 14.0 in` (`216 × 356 mm`) | Portrait | Journal visual summary, clinical ward handout, PDF supplement |
| `a3-clinical-sheet` | `11.69 × 16.54 in` (`297 × 420 mm`) | ISO A3 Portrait | Clinic / teaching hospital wall protocol |
| `digital-vertical` | `9.0 × 16.0 in` (`2700 × 4800 px` @ 300 DPI) | `9:16` | Mobile clinical reference & institutional communication |

## 2. Quantitative Integrity Rules
- Always include **denominators and units** (`per 100,000 person-years`, `28-day mortality`, `95% CI`).
- Prefer **relative + absolute risk** side-by-side (`ARR 6.8%`, `NNT = 15`) rather than isolated relative percentages that exaggerate clinical magnitude.
- Enforce WCAG 2.1 AA text contrast (`>= 4.5:1`) on all header banners and callout cards.
