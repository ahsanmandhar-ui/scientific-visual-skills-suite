# Scientific Visualization Guide

All visualizations generated by `scripts/generate_charts.py` are built directly from supplied numerical datasets or verified manuscript tables—never fabricated, smoothed with invented points, or artistically altered.

---

## 1. Non-Negotiable Scientific Visualization Rules

1. **Zero Data Fabrication:** Every plotted point, bar height, confidence interval whisker, survival step, confusion cell, and flow-diagram count must come verbatim from the input data.
2. **Axis Honesty:**
   - **Bar charts of counts, proportions, or rates MUST start at zero (`y = 0` or `x = 0`).** Never truncate a bar chart axis to exaggerate group differences.
   - **Ratio scales (Odds Ratio, Risk Ratio, Hazard Ratio)** in forest plots should use a **logarithmic axis** centered around the null value `1.0` (e.g., `0.25, 0.5, 1.0, 2.0, 4.0`) so reciprocal effects (`0.5` and `2.0`) have symmetric visual distance, falling back to linear only for narrow ranges if explicitly configured, and always marking the exact null reference line (`1.0` for ratios; `0.0` for mean differences).
3. **Uncertainty & Sample Size Reporting:**
   - Always plot 95% confidence intervals, standard errors, or interquartile ranges when present in source data, and explicitly state what error bars represent in the axis label or caption (`Error bars indicate 95% CI`).
   - Display total and group sample sizes (`N = ...`, `n = ...`) in group labels, legends, or figure captions.
4. **Direct Labeling & Minimal Chartjunk:**
   - Remove top and right axis spines (`despine`).
   - Use subtle low-contrast gridlines (`#E5E9F0`, `0.6 pt`) strictly along the quantitative axis.
   - Prefer direct value annotations or clean inline legends over distant floating legend boxes.
5. **Poster-Scale Native Sizing:**
   - Author charts at their **exact physical target dimensions in inches** on the poster with poster-legible typography (`18–26 pt` labels and ticks), exporting both **vector `.svg` / `.pdf`** (`pdf.fonttype = 42`, `svg.fonttype = 'path'`) and **300 DPI `.png`** (`600 DPI` when `.pptx` half-scale mode is active).

## 2. Supported Chart & Diagram Specifications (15 Types)

### Quantitative Statistical Plots
1. **`bar_chart` (Grouped / Horizontal / Vertical Bar Chart)**
   - Mandatory zero baseline; supports exact asymmetric `[ci_low, ci_high]` or symmetric `±SE`/`±SD` error bars, direct value labels preserving source decimal precision, and optional native editable PowerPoint chart embedding.
2. **`forest_plot` (Meta-Analysis & Subgroup Forest Plot)**
   - Multi-column publication layout:
     - Left text column: Study (`Author Year`) and optional subgroup headers.
     - Center graphical panel: Null vertical dashed line (`1.0` or `0.0`), study point-estimate squares scaled proportionally to inverse-variance weight, horizontal 95% CI whiskers (with arrows if clipped at axis limits), **pooled effect diamond** spanning `[pooled_ci_low, pooled_ci_high]`, and optional dashed **95% prediction interval** whiskers.
     - Right tabular column: Exact formatted `Effect (95% CI)` and `Weight (%)`.
     - Bottom statistical summary strip: Heterogeneity statistics ($I^2$, $\tau^2$, Cochran's $Q$, heterogeneity $p$-value, overall effect $p$-value) strictly as supplied or computed transparently from supplied study effects.
3. **`funnel_plot` (Publication Bias Funnel Plot)**
   - Plots study effect size ($x$-axis, log scale for ratios) against Standard Error ($y$-axis, **inverted** so high-precision large studies sit at the top apex), vertical line at pooled estimate, and dashed pseudo-95% confidence funnel lines ($\hat{\theta} \pm 1.96 \times \text{SE}$).
4. **`kaplan_meier` (Survival Curve with Number-at-Risk Table)**
   - Step-function survival probabilities (`where='post'`), optional translucent 95% CI ribbons, censored observation tick marks (`+`), HR & log-rank *p*-value callout from source data, and an aligned **Number at Risk** sub-panel directly beneath the time axis.
5. **`roc_curve` (Receiver Operating Characteristic Curve)**
   - Plots `1 − Specificity (False Positive Rate)` vs. `Sensitivity (True Positive Rate)` on `[0, 1]` square aspect axes, dashed `AUC = 0.50` chance diagonal, curve(s) labeled with exact `AUC (95% CI)`, and optional marked threshold point.
6. **`confusion_matrix` (Diagnostic Contingency Matrix)**
   - 2×2 or multi-class classification grid using perceptually uniform colorblind-safe sequential shading (`Cividis` / `Blues`), adaptive dark/light cell text showing **both raw count `n` and row/total percentage**, plus derived Sensitivity, Specificity, PPV, NPV caption notes when applicable.
7. **`scatter_plot` (Bivariate / Regression / Exposure-Response Plot)**
   - Encodes subgroups redundantly via **color + marker geometry** (`o`, `s`, `^`, `D`), optional fitted trend line and 95% CI ribbon from supplied model parameters, and exact correlation/slope annotation.
8. **`box_plot` (Statistical Box-and-Whisker Plot)**
   - Displays median, IQR (`Q1–Q3`), `1.5×IQR` whiskers, and optional overlaid jittered individual observations when `n <= 150` per group, with `n` printed under each category label.
9. **`violin_plot` (Kernel Density + Embedded IQR Box)**
   - Combines smoothed distribution density with an internal median point and interquartile bar; ideal for continuous biomarker or skewed outcome distributions with sufficient sample size (`n >= 20` per group).

### Clinical & Methodological Diagrams
10. **`prisma_diagram` (PRISMA 2020 Study Selection Flow Diagram)**
    - Three-phase vertical flow (*Identification* → *Screening* → *Included*) with lateral exclusion boxes listing exact reason counts and an automated **count-closure check** (`screened - excluded == sought`, `assessed - excluded_fulltext == included`). Any arithmetic mismatch in the source manuscript is flagged in the QA report rather than silently altered!
11. **`consort_diagram` (CONSORT Participant Flow Diagram)**
    - Tracks *Enrollment* (`Assessed`, `Excluded`) → *Randomization* (`N`) → parallel *Allocation* arms → *Follow-up* (`Lost to follow-up`, `Discontinued intervention`) → *Analysis* (`Analyzed per arm`), with arithmetic count-closure validation.
12. **`flow_diagram` (General Cohort / STROBE Selection Flow)**
    - Flexible multi-step cohort derivation or diagnostic cascade diagram with lateral exclusion branches.
13. **`workflow_diagram` (Experimental / Translational Protocol Diagram)**
    - Clean vector horizontal or vertical stage pipeline (e.g., *Cohort Assembly* → *Assay / Exposure* → *Statistical Modeling* → *Validation*) using typographic cards and crisp directional connectors—never fake stock clip-art.

### Structured Evidence Tables
14. **`characteristics_table` (Baseline Demographics / Study Characteristics Table)**
    - Rendered natively as an editable PowerPoint booktabs table (and optional standalone vector figure), preserving units (`mean ± SD`, `median [IQR]`, `n (%)`).
15. **`statistical_table` (Multivariable / Subgroup / Outcome Comparison Table)**
    - Displays unadjusted and adjusted estimates (`OR`, `RR`, `HR`, `β`), `95% CI`, and exact `p`-values, clearly distinguishing **Primary (Confirmatory)** from **Secondary / Exploratory** outcomes.
